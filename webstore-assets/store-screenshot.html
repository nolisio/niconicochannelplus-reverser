nicochannel.jp でのみ動作

拡張機能は https://nicochannel.jp/* 上でのみ動作し、他のサイトの音声には影響しません。

ブラウザ内でローカル処理

音声ルーティングは Web Audio API を使って端末内で処理されます。外部でのリモート処理はありません。

最小限のローカル保存のみ

保存するのは切り替え状態の小さな設定だけです。メディアファイルは保存しません。

単一の目的: nicochannel.jp の動画再生中に左右の音声チャンネルを入れ替えることだけを目的とし、音声や動画の送受信・再配布は行いません。
